# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, and keep discussions about the work.

## Reporting
Report unacceptable behavior privately to the maintainer, @xrazai. Reports are handled confidentially. The maintainer may remove comments, issues or PRs, and block participants who violate this code.
